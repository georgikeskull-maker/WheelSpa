# WheelSpa

Лендинг аренды мобильной бани-бочки — [wheelspa.ee](https://wheelspa.ee). Статический сайт на GitHub Pages, оператор — GVKFORGE OÜ.

## Состав
| Файл | Назначение |
|---|---|
| `index.html` | весь сайт: вёрстка, стили, скрипты, переводы (ET / RU / EN), калькулятор стоимости |
| `gallery-*.jpg`, `logo.png` | изображения |
| `CNAME` | домен `wheelspa.ee` для GitHub Pages |
| `sitemap.xml` | карта сайта |

## Как работает бронирование
Калькулятор считает стоимость в браузере. Заявка (дата, пакет, локация, дрова, телефон, имя) уходит `POST`-запросом
на серверный скрипт Google Apps Script, который пишет бронь в календарь и присылает уведомление владельцу.

- Код серверного скрипта и все его настройки в репозитории **не хранятся** (файлы `*.gs` в `.gitignore`).
- Токены, идентификаторы чатов и календаря лежат только в Script Properties самого Apps Script.
- В форме есть скрытое поле-ловушка `website` (honeypot): заполненные ботами заявки сервер отбрасывает молча.
- Сервер ограничивает частоту: не больше одной заявки с номера за 10 минут и общий потолок заявок в час.

## Правила для репозитория
Репозиторий **публичный**: всё, что попало в коммит, остаётся в истории навсегда.
Нельзя коммитить токены, ключи, пароли, файлы окружения, выгрузки заявок и личные данные клиентов.

## Внешние библиотеки
`flatpickr 4.6.13` (календарь выбора даты) подключается с jsDelivr по фиксированной версии и проверкой целостности (SRI).
Обновление: сменить версию в четырёх ссылках `index.html` и пересчитать `integrity`
(`openssl dgst -sha384 -binary <файл> | openssl base64 -A`).

## Локальная проверка
Откройте `index.html` в браузере или запустите в папке проекта
`python -m http.server 8000 --bind 127.0.0.1` и зайдите на `http://localhost:8000`.
Сервер запускайте только на время проверки и останавливайте после.
